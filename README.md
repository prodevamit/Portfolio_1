# Portfolio 1

A modern, responsive personal portfolio landing page built with plain HTML, CSS, and JavaScript. This project is designed to showcase a developer/designer's profile, selected work, about section, and contact details in a sleek and minimal style.

## Live Preview

Open `index.html` directly in your browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Clean and modern portfolio layout
- Responsive design for desktop and mobile
- Sticky navigation header
- Hero section with call-to-action buttons
- Animated marquee section for skills and disciplines
- Project showcase cards
- About section with value highlights
- Contact section with email and social links
- Auto-updating footer year using JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Portfolio_1/
```

## Files Overview

- `index.html` — Main portfolio structure and content
- `styles.css` — All styling, layout, colors, and animations
- `script.js` — Small JavaScript enhancements like dynamic year updates and availability text

## Customization

You can personalize the portfolio by editing the content in `index.html`:

- Name and branding
- Personal intro
- Project titles and descriptions
- About section details
- Email and social links
- Footer text

You can update the visual design in `styles.css`, including:

- Colors
- Typography
- Spacing
- Card layouts
- Animations

The current year is automatically generated by `script.js`, so the footer stays up to date.

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser, or run a local server
3. Customize the content and styling to fit your portfolio
4. Deploy it to GitHub Pages, Netlify, or any static hosting provider

- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
